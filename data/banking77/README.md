# BANKING77

Copy of the BANKING77 dataset (Casanueva et al., 2020, PolyAI), from
https://github.com/PolyAI-LDN/task-specific-datasets (`banking_data/`), licensed
CC BY 4.0. It is the same data as the Hugging Face dataset `PolyAI/banking77`.
Committed so a clean machine can run the stack without the Hugging Face Hub.
